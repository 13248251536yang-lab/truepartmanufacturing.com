# Truepart Manufacturing Co., Ltd. — website starter

A responsive static website starter for Cloudflare Pages.

## Files
- `index.html` — page content
- `styles.css` — layout and styling
- `script.js` — mobile navigation and inquiry email preparation

## Before publishing
1. In `script.js`, replace `REPLACE-WITH-YOUR-EMAIL@example.com` with your real business email address.
2. Review every service description and only keep services your company actually provides.
3. Add your real contact details, certifications, photos, and company-specific facts only after verifying them.
4. Upload these files to the root of the `company-website` GitHub repository.
5. Cloudflare Pages settings for this plain static site: Framework preset `None`, Build command blank, Build output directory `.`

The inquiry form opens the visitor's email application; it does not send form submissions to a server.
